# Optical Illusion Museum

Unity VR/3D museum project for EE267. The current scene includes an Ames Room exhibit and a rotating Ames Window exhibit.

## Requirements

- Unity Hub
- Unity Editor version used for this project: Unity 6000.4.7f1
- Universal Render Pipeline support
- Git LFS installed

## How to Open in Unity

1. Open Unity Hub.
2. Click **Add** or **Add project from disk**.
3. Select the cloned `EE267` folder.
4. Open the project with Unity `6000.4.7f1`.
5. If Unity asks to install missing packages, allow it.

## How to Run

1. In Unity, open:

   `Assets/Scenes/AmesRoom.unity`

2. Press the **Play** button.

## Controls

- `W` / `A` / `S` / `D`: move around
- Mouse left/right: turn the player body
- Mouse up/down: look up and down
- `Shift`: move faster
- `Esc`: unlock mouse
- Left click: lock mouse again

## How to Download

```bash
git clone https://github.com/thutamay/EE267.git
cd EE267
git lfs pull
```
